Mampho Salon Booking System

Project Overview
Mampho Salon Booking System is a web application developed to make booking salon appointments easier. Customers can select salon services, view prices and submit appointment requests.

Technologies Used
C#
ASP.NET Core
Razor Pages
HTML and CSS

Main Features
Customer appointment booking form
Service selection and pricing
Customer contact details
Appointment notes
Booking management page for administrators
Ability to remove bookings

How It Works
Customers complete the booking form by entering their details, selecting a service and choosing an appointment date. The application processes the booking and displays submitted bookings on the management page.
Current Project Status
This project is still under development. Bookings are currently stored temporarily in memory. Database integration and permanent booking storage are planned for future development.

Learning Experience
This project helped me develop my understanding of C#, ASP.NET Core Razor Pages, web application structure, form handling and basic booking management. AI tools were also used as learning and development assistance.
